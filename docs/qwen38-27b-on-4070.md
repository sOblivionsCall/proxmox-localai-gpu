# Qwen3.8-27B on the Proxmox LocalAI node (RTX 4070 12 GB) — validated 9/4/26

The 27B model runs on the 12 GB 4070 with **full GPU offload**. It took four
attempts; the failure modes are the value of this note.

## The working config

`/opt/localai/models/qwen38-27b-ud-iq3xxs.yaml` in CT 112:

```yaml
name: qwen38-27b-ud-iq3xxs
backend: llama-cpp
context_size: 4096
gpu_layers: 99
cache_type_k: q8_0
cache_type_v: q8_0
parameters:
  model: Qwen3.8-27B-UD-IQ3_XXS.gguf
  batch: 512
options:
  - reasoning_format:none
  - n_parallel:1        # ← the load-bearing line
```

Model: `unsloth/Qwen3.8-27B-GGUF` → `Qwen3.8-27B-UD-IQ3_XXS.gguf` (10.9 GB).

## The three failure modes, in order of discovery

1. **KV cache OOM at 8k ctx** (`cudaMalloc failed: out of memory` on a 4.2 GiB
   allocation). 10.9 GB weights + 8k ctx KV + compute buffers > 12 GB.
   Fix: `context_size: 4096`.
2. **Partial offload is architecturally impossible for this model.** With
   `gpu_layers: 48`, llama.cpp aborted: `layer 0 is assigned to device CPU
   but fused Gated DeltaNet (chunked) is assigned to device CUDA0`. The
   fused Gated DeltaNet ops refuse a CPU/GPU split — it's all-or-nothing
   for this hybrid-attention architecture. Partial `gpu_layers` is not an
   option here.
3. **The real blocker: `parallel=4` (LocalAI default) × the recurrent
   state.** Qwen3.8 has 48 Gated DeltaNet layers holding a fixed-size
   recurrent state allocated **per sequence**. The community-scripts engine
   sets `LLAMACPP_PARALLEL=4` by default → 4 × the rs-cache → a single
   **4.2 GiB** tensor allocation that failed even at 4096 ctx with
   `gpu_layers` omitted (auto-fit disabled itself when the user value was
   present). Fix: **`n_parallel:1` in the model YAML options** — the rs-cache
   drops to one sequence and the whole model fits with ~0.3 GB headroom.

   - The `parallel="4"` in the runtime log is the smoking gun. It comes from
     the engine's `LLAMACPP_PARALLEL` default, overridable per-model with the
     `n_parallel:1` YAML option (LocalAI discussion #1670 has the history).
   - MTP head was auto-detected (`draft-mtp` enabled) but the 4070's budget
     doesn't include the extra draft rows; leave it off here.

## Context size trade-off at 12 GB

Weights 10.9 + rs-cache 0.15 (parallel=1) + KV (q8_0, 16 attention layers):
- 4096 ctx: ~0.13 GB KV → fits with ~0.3 GB headroom ← current config
- 8192 ctx: ~0.5 GB KV → OOM (this is what failed in attempt 1)

If more context is needed, the next lever is `q4_0` KV cache types
(dropped from q8_0), worth ~2x context — untested on this card.
